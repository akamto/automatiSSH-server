Descarga tu automatiSSH-server.sh generado.

        

          

            
            automatiSSH-server.sh
            
          

          

        

        

          
          
        

      


      

        
Paso 1 — Ejecuta el script en tu servidor

        

          

            terminal — bash
            
          

          
sudo chmod +x automatiSSH-server.sh
sudo ./automatiSSH-server.sh

        

        
Paso 2 — Conéctate con tu contraseña

        

          

            terminal — bash
            
          

          
ssh -p puerto usuario@servidor

        

      


      

        
Paso 1 — En tu equipo (cliente): crea tu clave y cópiala al servidor

        

          

            terminal — cliente
            
          

          
ssh-keygen -t ed25519 -a 100 -f /home/usuario/.ssh/nombre -N "PASSPHRASE"
ssh-copy-id -i /home/usuario/.ssh/nombre.pub -p puerto usuario@servidor

        

        
Paso 2 — En el servidor: ejecuta el script

        

          

            terminal — servidor
            
          

          
sudo chmod +x automatiSSH-server.sh
sudo ./automatiSSH-server.sh

        

        
Paso 3 — Desde tu equipo (cliente): conéctate con tu clave

        

          

            terminal — cliente
            
          

          
ssh -i /home/usuario/.ssh/nombre -p puerto usuario@servidor
